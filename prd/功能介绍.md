
# 家庭资产管理系统 - 让家庭管理更轻松

## 🌟 系统简介

您是否常常找不到家里的物品？是否想记录家庭的每一笔资产？是否希望留下美好的家庭回忆？

**家庭资产管理系统** 正是为解决这些问题而生！这是一款专为现代家庭打造的综合性管理平台，让家庭生活更加有序、温馨。

---

## 📱 功能模块

### 🏠 一、资产管理 - 家庭财务一目了然

**核心功能：**
- 资产总览：直观展示家庭总资产、负债、净资产
- 分类管理：房产、车辆、存款、投资等多种类型
- 变动追踪：记录每一笔资产增减变化
- 数据统计：饼图展示资产配置比例

**【效果图位置】：插入资产总览页面截图**

---

### 📷 二、相册管理 - 珍藏美好瞬间

**核心功能：**
- 主题相册：按旅行、生日、节日等创建主题
- 批量上传：支持一次上传多张照片
- EXIF提取：自动获取拍摄时间和地点
- 时间线浏览：按时间顺序回顾美好时光

**【效果图位置】：插入相册时间线页面截图**

---

### 🎒 三、物品管理 - 再也不丢东西

**核心功能：**
- 物品登记：记录名称、类别、购买日期、存放位置
- 库存预警：低于设定数量自动提醒补货
- 位置管理：创建家庭存放位置（如客厅、卧室、储物间）
- 快速搜索：输入关键词快速定位物品

**【效果图位置】：插入物品列表页面截图**

---

### 👕 四、衣服管理 - 智能衣柜管家

**核心功能：**
- 衣物分类：上衣、裤子、裙子、外套等
- 收纳管理：记录每件衣服的存放位置
- 搭配记录：保存喜欢的穿搭组合
- 季节提醒：换季时自动提醒整理衣物

**【效果图位置】：插入衣服管理页面截图**

---

### 🍳 五、厨房管理 - 美食记录专家

## 🚀 快速开始

### 环境要求
- Java 8 及以上版本
- MySQL 8.0 及以上版本
- 现代浏览器（Chrome、Firefox、Safari）

### 部署方式

**方式一：Docker 一键部署**
```bash
# 进入项目目录
cd family-manage

# 构建并启动容器
docker-compose up -d
```

**方式二：本地运行**
```bash
# 启动后端服务
cd family-manage-backend
mvn spring-boot:run

# 启动前端服务
cd family-mange-frontend
npm install
npm run dev
```
