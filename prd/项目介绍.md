
# 家庭资产管理系统 - 技术架构与功能详解

## 项目概述

**家庭资产管理系统** 是一款面向现代家庭的综合性资产管理平台，旨在帮助家庭成员高效管理各类资产、记录生活点滴、规划家庭事务。系统采用现代化的技术架构，提供稳定可靠的服务支撑。

### 核心技术特性

#### 1. 安全认证机制

系统采用基于 Token 的无状态认证方案：

```java
// 认证拦截器核心逻辑
public class AuthInterceptor implements HandlerInterceptor {
    @Override
    public boolean preHandle(HttpServletRequest request, 
                           HttpServletResponse response, 
                           Object handler) {
        String token = request.getHeader("Authorization");
        // Token 验证与用户信息解析
        AuthUser user = parseToken(token);
        AuthContext.setUser(user);
        return true;
    }
}
```

#### 2. 文件存储方案

集成 MinIO 实现分布式文件存储：

```java
@Configuration
public class MinioConfig {
    @Bean
    public MinioClient minioClient(MinioProperties properties) {
        return MinioClient.builder()
                .endpoint(properties.getEndpoint())
                .credentials(properties.getAccessKey(), properties.getSecretKey())
                .build();
    }
}
```

#### 3. 多数据源支持

通过 Dynamic Datasource 实现读写分离：

```yaml
spring:
  datasource:
    dynamic:
      primary: master
      datasource:
        master:
          url: jdbc:mysql://localhost:3306/family_manage
          username: admin
          password: password
        slave:
          url: jdbc:mysql://localhost:3307/family_manage
          username: readonly
          password: password
```

### 核心功能详解

#### 1. 家庭资产管理

- **资产概览**：展示家庭总资产、负债、净资产统计
- **资产分类**：按类型（房产、车辆、金融资产等）分类管理
- **变动记录**：追踪资产增减变动历史

#### 2. 相册管理

- **主题相册**：创建自定义主题，分类存放照片
- **照片上传**：支持批量上传，自动提取 EXIF 信息
- **时间线浏览**：按拍摄时间顺序展示照片

#### 3. 物品管理

- **物品登记**：记录物品名称、类别、存放位置
- **库存预警**：设置库存下限，自动提醒补货
- **位置管理**：管理家庭各存放位置

#### 4. 厨房管理

- **菜谱管理**：收录家庭菜谱，支持图片上传
- **食材管理**：库存管理与采购清单
- **烹饪记录**：记录每次烹饪的菜品与心得

#### 5. 财富管理

- **资产配置**：管理各类投资产品
- **收益追踪**：记录买入卖出，计算收益
- **类型统计**：按资产类型统计配置比例

## 部署方案

### Docker 容器化部署

系统提供完整的 Docker 部署支持：

```bash
# 构建后端镜像
docker build -f docker-build/Dockerfile.backend -t family-manage-backend .

# 构建前端镜像
docker build -f docker-build/Dockerfile.frontend -t family-manage-frontend .

# 一键部署（使用 docker-compose）
docker-compose up -d
```

## API 接口设计

### 接口规范

- **协议**：HTTP/HTTPS
- **数据格式**：JSON
- **字符编码**：UTF-8
- **认证方式**：Bearer Token

### 响应格式

```json
{
    "code": 200,
    "message": "success",
    "data": { ... },
    "timestamp": 1699999999999
}
```

### 核心接口示例

| 模块 | 接口 | 方法 | 功能 |
|------|------|------|------|
| 认证 | `/api/auth/login` | POST | 用户登录 |
| 资产 | `/api/asset/summary` | GET | 获取资产概览 |
| 相册 | `/api/album/photos` | POST | 上传照片 |
| 物品 | `/api/goods/items` | GET | 查询物品列表 |
| 厨房 | `/api/kitchen/dishes` | POST | 新增菜谱 |

## 安全性考虑

1. **密码加密**：采用 BCrypt 算法加密存储
2. **SQL 注入防护**：使用 MyBatis Plus 预编译语句
3. **XSS 防护**：前端输入校验与后端过滤
4. **权限控制**：基于角色的访问控制（RBAC）
5. **日志审计**：关键操作记录日志
